# Namgay Wangchuk - Personal Portfolio

A responsive personal portfolio website built with plain **HTML, CSS and JavaScript** (no build step).

## Features
- Sections: Home, About, Skills, Projects, Education, Contact
- Responsive layout for desktop, tablet and mobile
- Dark / light theme toggle (remembers your choice)
- Mobile hamburger menu, smooth scrolling, active-link highlighting
- Typing animation, scroll-reveal effects, animated skill bars and counters
- Project filter buttons
- Contact form with live validation
- Back-to-top button and scroll progress bar
- Accessible: semantic HTML, keyboard focus styles, reduced-motion support

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Deploy on GitHub Pages
1. Create a new public repository named `portfolio` on GitHub.
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://<your-username>.github.io/portfolio/`.
